# VN Biodiversity WebGIS AI

Python workspace for machine learning, NLP, computer vision, generative AI,
and language-model research used by VN Biodiversity WebGIS.

## Package areas

- `vision`: species identification and image/video analysis.
- `ml`: classical machine learning and GeoAI workflows.
- `nlp`: scientific text processing and information extraction.
- `genai`: generated descriptions and multimodal enrichment.
- `llm`: language-model training, evaluation, and RAG experiments.

Datasets and generated artifacts are intentionally excluded from Git. Keep
reproducible preparation and training code in `training` and experiment work in
`notebooks`.
